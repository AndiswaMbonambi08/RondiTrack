ASSIGNMENT 7.4 - RECORD A CONTRIBUTION

WHAT WE DID
A form records a payment. Money is sent as whole cents (no rounding errors).
Each payment has a unique Idempotency-Key, and a retry after a dropped
connection reuses it, so the API never records the same payment twice.

FILES AND WHY

API
- Services/StokvelService.cs
  Takes cents, converts them to rands exactly, and refuses closed cycles (409).
- Endpoints/PagedListEndpoints.cs
  The members list returns names for the Treasurer's picker.

FRONTEND
- src/money/money.ts
  Converts typed rands to cents and back with no floating point.
- src/contributions/useIdempotencyKey.ts
  Makes one key per payment and keeps it on retries.
- src/contributions/ContributionForm.tsx
  The form, with the member picker for Treasurers only.
- src/contributions/contributionErrors.ts
  Turns API errors (400, 409, 422, 429, network) into clear messages.
- src/contributions/recordContribution.test.tsx
  MSW tests proving the key stays the same on retries.
