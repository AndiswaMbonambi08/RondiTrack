ASSIGNMENT 7.3 - WHAT CHANGED AND WHY
==============================================================

BACKEND (repo root)
- Program.cs
  AddOpenApi now has a schema transformer that adds `correlationId` to the
  ProblemDetails schema. The API already sends it, but the OpenAPI document did
  not declare it, so the generated frontend types lacked it. Fixed in the API
  instead of widening the type by hand in the frontend.
- Endpoints/MeEndpoints.cs
  New GET /api/v1/me endpoint returning who the signed-in member is.
- RondiTrack.Tests/Integration/MeEndpointTests.cs
  Tests for the new /me endpoint.
- RondiTrack.Tests/Integration/OpenApiContractTests.cs
  Test that the OpenAPI ProblemDetails schema declares correlationId.

FRONTEND (web/src)
- api/schema.d.ts
  Generated by `npm run api:types` from the API's OpenAPI document. Never edited
  by hand.
- api/apiError.ts
  ApiError class: status, problem+json body (generated type) and Retry-After.
- api/queries.ts
  Query key factory scoped by stokvel id, plus hooks: useMe, useHome,
  useStokvels, useStokvel, useCycles and useContributions (infinite query).
  The stokvel list comes from /me/home because GET /stokvels is admin only.
  No keepPreviousData on contributions, so switching stokvels never shows the
  old stokvel's rows. The "no next page" value from the API is "".
- features/StokvelWorkspace.tsx
  Uses the real API field names (amountCents, cycleLabel) and the "confirmed"
  status. Stokvel switcher is now buttons. Green theme, wordmark, theme toggle.
- features/StokvelWorkspace.test.tsx
  Stokvel switch test. The fake API answers the second stokvel slowly, so the
  test proves no previous stokvel amounts are on screen right after a switch.
- components/Wordmark.tsx (new)
  RondiTrack logo text used on the sign-in page and the header.
- components/LoginForm.tsx
  Green restyle, theme toggle, and errors shown through describeError.
- components/ThemeToggle.tsx
  Single sun/moon icon button instead of three buttons.
- main.tsx
  App wrapped in ThemeProvider.
- test/setup.ts
  Stub for window.matchMedia, because jsdom does not have it and the theme
  toggle needs it in tests.

DOCS
- README.md
  Single-flight proof (failing and passing output), Stokvel switch proof
  (failing and passing output), Shared phone check, Known gaps.
- docs/proofs/ (4 files)
  Saved output for: single-flight failing, single-flight passing, switch test
  failing with keepPreviousData, switch test passing.
- docs/screenshots/devtools-no-stokvel-a.png
  Query Devtools after sign-out: no query for the other member's stokvel.
